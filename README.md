# DirectEdit-proto
DirectEdit is a simple Python Text editor and it has some interesting features
## how to use
1. execute python script
2. type file name and hit "enter" key
3. type in (w) for write, (r) for read, (a) for append, (x) for create
type the incorrect option in and you will add 404 bytes to a file
Do what the question asks
##  interesting feature(s)
- disk space punishment(if you made an error, useless data will be added
